# Orbisent — Vision

**Tagline:** Beyond the Known.

## 1. Mission

Orbisent aims to make powerful, personalized AI assistance accessible to everyone.

Our goal is to move beyond chatbots toward AI agents that understand a user's goals, work with their digital environment, execute useful tasks, and help people accomplish more with less effort.

## 2. The Core Idea

A person should not need to spend hours configuring an AI assistant.

Orbisent envisions a future where anyone can create a personalized AI agent in about a minute. The agent adapts to the user's preferences, tools, workflows, and goals.

Instead of merely explaining how to do something, it should be able to do it—with appropriate permission.

## 3. The User Experience

The intended experience is simple:

1. The user creates their personal agent.
2. The user describes a goal in natural language or by voice.
3. Orbisent determines the steps required.
4. The agent uses available tools to complete the task.
5. The user receives a clear report of what happened.

Example: "Create a project folder, organize these documents, and draft personalized messages for five clients."

Orbisent should plan the work, perform permitted actions, and report what succeeded or failed.

## 4. Long-Term Capabilities

The long-term vision includes:

- Personalized agents that adapt to individual workflows.
- Multi-step task execution across supported applications.
- Natural voice interaction.
- Persistent, user-controlled memory and preferences.
- Local execution and offline capabilities where hardware and software permit.
- An extensible ecosystem of tools and integrations.
- Broad access to useful AI capabilities, with a strong commitment to affordability and free access.

These are long-term goals, not claims that every capability exists today.

## 5. Core Principles

**Action over conversation.** Help users achieve outcomes, not just generate text.

**Personalization.** Every agent should reflect its user's needs and preferences.

**Accessibility.** Powerful AI should be available to people without expensive subscriptions or specialized technical knowledge.

**Privacy and control.** Users should understand what their agent can access and change those permissions.

**Reliability.** The agent must report uncertainty, errors, and incomplete tasks honestly.

**Safety by design.** Sensitive actions—such as sending messages, deleting files, or making purchases—must have appropriate safeguards and confirmation.

**Incremental progress.** Build capabilities that work reliably before expanding their scope.

## 6. Technical Philosophy

Orbisent is a product vision, not a commitment to one neural network architecture.

The system may combine language models, planning, memory, tool execution, permissions, and local or remote computation.

We will evaluate existing open models and other suitable components before deciding which capabilities require original model research or training.

Custom model development should solve a demonstrated problem that existing approaches cannot adequately address.

## 7. Initial Product Direction

The first milestone is a small, working agent that can complete at least one useful task from beginning to end.

The initial prototype should:

- Accept a natural-language instruction.
- Break the instruction into manageable steps.
- Use a limited set of tools.
- Execute actions within an explicitly defined scope.
- Report results and errors.
- Request confirmation before consequential actions.

The first milestone is not a fully autonomous assistant capable of doing everything. It is a reliable foundation that can be tested and improved.

## 8. Research Questions

Orbisent will investigate:

- How can a personal agent be configured in approximately one minute?
- How can agents reliably complete multi-step tasks?
- How can personalization improve usefulness without compromising privacy?
- Which tasks can run locally, including without an internet connection?
- When is a custom model genuinely better than an existing model?
- How can useful AI capabilities be delivered at very low cost?

We will test assumptions through experiments rather than treating aspirations as established facts.

## 9. Definition of Progress

Progress means measurable improvements in:

- Tasks completed successfully.
- Reliability across repeated attempts.
- Time and effort saved for users.
- Cost per completed task.
- Privacy, transparency, and user control.
- Accessibility across different devices.

## 10. The Long-Term Vision

Orbisent aims to help make personal AI agents a practical tool for everyday life—not just a technology available to a small group of experts.

**Beyond the Known.** Explore what is possible, build what is useful, and prove it through working technology.
